# iOS Companion Plan

This app is a companion, not the primary file mover.

## Role
- Trigger desktop jobs remotely.
- Monitor progress/report status.
- Review unmatched tracks and approve actions.

## Why companion-only
iOS cannot reliably perform full desktop Rekordbox USB export workflows alone due to filesystem and USB access limits.

## MVP screens
1. Job Launcher (select source preset + USB preset)
2. Live Logs
3. Truth Report Summary (matched/unmatched/duplicates)
4. Safe Actions (approve sync, approve format)
